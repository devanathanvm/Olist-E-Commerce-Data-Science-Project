# 🛒 Olist E-Commerce Business Analysis

## 📌 Overview
A complete data science project analyzing the Olist Brazilian e-commerce 
dataset to uncover business problems, extract signals, and build 
models that support data-driven decisions.

## 📁 Project Structure

| File | Description |
|------|-------------|
| `N1_DataCartography_Olist.ipynb` | Data mapping — understanding the dataset structure |
| `N2_DataDeepDive_Olist.ipynb` | In-depth exploratory data analysis (EDA) |
| `N3_SignalExtraction_Olist.ipynb` | Feature engineering & pattern extraction |
| `N4_ModelsToDecisions_Olist.ipynb` | ML models & business decision support |
| `Olist_Business_Problems_Report.docx` | Business problem framing & recommendations |
| `Olist_Technical_Report.docx` | Technical methodology & findings |

## 🔍 Key Areas Covered
- Data exploration & quality assessment
- Customer behavior & sales trend analysis
- Signal extraction & feature engineering
- Predictive modeling for business decisions
- Actionable business recommendations

## 🛠️ Tools & Technologies
- Python (Pandas, Scikit-learn, Matplotlib, Seaborn)
- Jupyter Notebooks
- Microsoft Word (Reports)

## 📊 Dataset
[Olist Brazilian E-Commerce Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) — publicly available on Kaggle.
